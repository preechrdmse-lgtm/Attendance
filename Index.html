📖 คู่มือเชื่อมต่อ TikFinity / OBS

1) TikFinity

เปิด TikFinity Desktop ใส่ชื่อ TikTok แล้วกด Connect to Live จากนั้นกรอก WebSocket ด้านล่างแล้วกดเชื่อมต่อ (ค่าเริ่มต้นของ TikFinity มักเป็น ws://localhost:21213 ตรวจพอร์ตในโปรแกรมอีกครั้ง)

ยังไม่เชื่อมต่อ

2) OBS Browser Source

ดาวน์โหลดไฟล์นี้ไว้ในเครื่อง → OBS: Sources + → Browser → ไม่ติ๊ก Local file แล้วใส่ URL เช่น

file:///C:/live/khwan.html?ws=ws://localhost:21213&clean=1

ขนาด 1920×1080 ติ๊ก Control audio via OBS · clean=1 ซ่อนแผงแชท · ถ้าเสียงไม่ดัง ให้คลิกขวา Interact แล้วกดปุ่มเริ่ม

3) รูปแบบ Event ที่รับ

{"event":"chat","data":{"nickname":"น้องใบเตย","comment":"สาธุ"}}
{"event":"gift","data":{"nickname":"พี่หมู","giftName":"Rose","repeatCount":3,"diamondCount":1}}
{"event":"like" | "follow" | "share" | "member","data":{"nickname":"..."}}

4) คำสั่งในแชท

สาธุ/ไหว้ ไหว้พระ · รำ/วง เร่งรำ 8 วิ · ทอง ปิดทององค์เจดีย์ · ดอกไม้ พุ่มเงินทองโต · กลอง กลองยาวรัว · เร็ว/ช้า ปรับจังหวะ · Gift เพิ่มทอง ดอกไม้ และคู่รำ · Follow เพิ่มคู่รำ (สูงสุด 6)

5) ทดสอบ

Console: khwan.event('gift',{nickname:'ทดสอบ',giftName:'Rose',diamondCount:50}) หรือ postMessage รูปแบบเดียวกัน

หมายเหตุ: ถ้าเปิดจากลิงก์เว็บ (https) เบราว์เซอร์หรือนโยบายความปลอดภัยอาจบล็อกการต่อ ws://localhost ให้ดาวน์โหลดไฟล์ไปเปิดในเครื่องแทน
